# Boulder: Yesterday & Today — social/email image set

Curated from Robert Castellino's book *Boulder: Yesterday & Today — A Photographic
Retrospective*. These eight are the strongest standalone frames for organic social
and email; they're in `library.json` with per-image credits.

**Resolution caveat — read before paid use.** The book file we have is a low-res
export: each page is ~1008px wide, so these crops are ~1000–1200px. Fine for
organic posts, stories, and email headers; **too small for paid ads or print.**
Hi-res originals clearly exist (the companion "Brief History" file holds the same
images at 3200px). For a paid campaign, get the full-res originals from Bob.

**Credits / rights.** Two kinds of images:
- **Today** — modern color frames by **Robert Castellino** (Bob owns these).
- **Yesterday** — archival frames credited to the **Carnegie Branch Library for
  Local History / Boulder Historical Society**, photographers like **Joseph B.
  Sturtevant ("Rocky Mountain Joe")** and **Vern Walker (Marsha Walker Collection)**.
  Fine for organic posts that promote the book; **a paid ad using an archival or a
  living person's image needs a rights check first.**

The "then/now" pair to lead with: **`sunset-hill-1905.jpg` ↔ `sunset-hill-2005.jpg`**
— the same view from Sunset Hill, exactly 100 years apart.

Source PDFs are kept out of git in `resources/` (paid product). See
`docs/boulder-yt-content-kit.md` for the post + email plan.
